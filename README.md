## How to run locally

1. Clone the repository:

   git clone https://github.com/raselahmed1337/ahmedrasel.git
2. Open the project folder and open index.html in your browser, or serve with a simple HTTP server:

   python -m http.server 8000

3. For Python projects, create a virtual environment and install required packages (if any):

   python -m venv venv
   source venv/bin/activate  # macOS/Linux
   venv\Scripts\activate   # Windows

   pip install -r requirements.txt
